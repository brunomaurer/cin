# CIN Vault

Gemeinsames Wissens- und Entscheidungs-Repository der CIN-Founder.

## Struktur

| Ordner | Zweck | Wer schreibt |
|---|---|---|
| `00_Strategie/` | Positionierung, Pricing, Vision (read-only Referenz) | Bruno |
| `01_Decisions/` | ADRs (Architecture Decision Records) — jede Entscheidung datiert | Alle Founder |
| `02_Specs/` | Feature-Specs BEVOR gebaut wird — alle kommentieren | Bruno, Mischa |
| `03_Roadmap/` | Now / Next / Blocked pro Person | Alle |
| `04_Marketing/` | Content-Plan, GEO, Webinare, Funnel | Urs |
| `05_Analyse/` | Code-Analysen, Technische Bewertungen, Vergleiche | Claude / Bruno |
| `90_Agent-Log/` | Claude Code schreibt Fortschritt hierhin | Claude |

## Verwendung

1. Mit Obsidian als Vault oeffnen (`vault/` Ordner)
2. Aenderungen via Git committen und pushen
3. Alle Founder koennen async lesen und kommentieren
