# Weg C — CIN Abwickeln

> Analyse: 2026-05-28

## Zusammenfassung

Gesellschaft aufloesen, keine weitere Investition, bestehende Vertraege auslaufen lassen.

## Wann diese Option Sinn macht

1. **Kein Founder-Alignment** — wenn sich die 4 Founder nicht auf einen gemeinsamen Weg einigen koennen
2. **Kein Product-Market-Fit** — 3 Kunden nach 3 Jahren koennte bedeuten: der Markt will das Produkt nicht (oder nicht so)
3. **Opportunitaetskosten** — die Zeit die Bruno, Mischa, Alexander und Urs in CIN stecken, koennte woanders mehr Wert erzeugen

## Was zu klaeren waere

- Bestehende Kundenvertraege: Kuendigungsfristen, Verpflichtungen
- Gesellschaftsvertrag: Aufloesung, IP-Rechte, Haftung
- Daten der Kunden: Rueckgabe/Export-Pflicht
- Domain, Hosting, Azure DevOps: Abwicklung

## Ehrliche Frage vorher

Bevor ihr einstampft: **Warum sind es nur 3 Kunden nach 3 Jahren?**

- Ist das Produkt falsch? → Dann hilft auch Greenfield nichts
- Ist der Vertrieb falsch? → Dann koennte ein besseres Produkt + Urs' Marketing reichen
- Ist der Preis falsch? → 25k/Jahr ist viel fuer ein Tool das 3 Leute zum Setup braucht
- Ist der Markt zu klein? → Innovationsmanagement ist eigentlich ein wachsender Markt

Die Antwort auf diese Frage bestimmt ob Option B (Greenfield) Sinn macht oder ob Einstampfen die ehrlichere Antwort ist.
